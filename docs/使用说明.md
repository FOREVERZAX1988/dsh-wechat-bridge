## 3. 怎么起停

```powershell
$base = "http://127.0.0.1:50247/dsh-wechat-bridge"   # 端口 = DSH 界面那个端口，重启后可能变
Invoke-RestMethod "$base/state"                                        # 状态 + 两边日志
Invoke-RestMethod "$base/bridge/start" -Method Post -Body '{}' -ContentType 'application/json'
Invoke-RestMethod "$base/bridge/stop"  -Method Post -Body '{}' -ContentType 'application/json'
```

**DSH 重启后桥接不会自动起来**，要再点一次「启动」（或上面这条）。会话本身会自动重新挂上，不用重建。

### 重启电脑之后怎么起（2026-11-05 加的开机自启）

1. **微信**：开机项里有 `Weixin -autorun`，会自己弹出来；**要确认已经登录**（没登录＝读不到库、也发不出去）。
2. **DSH**：目前**不会**自动启动，得手动打开 `DeepSeek Harness`。
3. 等 ~20 秒：插件在 DSH 起来 8 秒后**自动拉起桥接**，日志里会出现
   `开机自启：正在拉起桥接…` → `桥接已启动 → http://127.0.0.1:<端口>`，再过十来秒 UIA 预热完就能收发。
4. 想确认：`/state` 里 `桥接.运行中 = true`。

**没起来就双击桌面上的「启动大肥鱼.bat」**（`~/.dsh/vendor/dsh-wechat-bridge/launch.ps1`）：它会自己找 DSH 的端口，
已经在跑就只报状态，没跑就拉起来。

不想让它自启：配置里把 `开机自启` 改成 `false`。

图形界面：**设置 → 通到微信**（插件是热加载的，页面可能要重启一次 DSH 才出现；没有页面也能用上面的接口）。

## 4. 想让它闭嘴（重要）

```powershell
# 只暂停"发出去"：消息照收、照回，但只在日志里写"该发什么"

# 全停：一条都不进、一条都不发

```

恢复真发：`-Body '{"试运行":false,"总开关":true}'`

## 6. 群里怎么用

**不再是「必须点名」了**：`活跃群` 里那两个群，所有消息都会带上前 8 条上下文转进会话，
模型自己判断「这话我有没有话说」——

- 有话想说、或者话头明显在问什么 → 自然接一两句；
- 没话 → 只回 `[不回]`，宿主会把这条整个丢掉，微信里一个字都不会出现。

所以群里看到的效果是：它偶尔自己插一句，像个潜水但懂行的朋友，不是机器人应答机。

频率闸（按群算）依然在：**两条回复至少隔 45 秒**，**一小时最多接 8 次**。撞闸的消息干脆不转进来（省钱）。
想更活跃就调这两个数（`群回复间隔秒` / `群每小时上限`），想更安静就调小。

**没点名、也不是主人说的群消息，先按好感度掷一次骰子**（2026-11-06 加，11-09 重新校准过）：
好感分来自 `wechat-affinity.json`（聊得越多分越高，每聊一条 +0.2）。

| 好感分 | 命中率 |
| --- | --- |
| 0（陌生） | 30% |
| 1.0 | 42% |
| 3.0（lilab / 初八） | 66% |
| 3.6（凇） | 73% |
| 5.0+ | 85%（封顶） |

公式在 `接话概率()`：`0.30 + 好感分 × 0.12`，夹在 25%~85%。掷骰子没中的会写一行日志
`群接话：某某（好感 X）这次不接，命中率 Y%`，方便事后调。

> 教训：11-06 晚上压到 `0.08 + 0.07`（8%~50%），结果两天里群消息只转进模型 55 条，
> 其中 41 条是主人自己说的 —— 朋友的话七成在桥接层就被挡掉了，看起来就像「只跟主人聊」。
> 频率闸才是防刷屏的那道，骰子不该压这么死。

过了骰子也不一定开口：**提示词要求它先看上面几条上下文**——别人互聊、话题翻篇、插不上嘴的都不回；
拿不准或者只想表个态，就**只回一个表情**（回复只写 `[表情: 震惊]`，不带别的字），桥接会当纯表情包发出去。

- **点名必回**：正文里有 `大肥鱼` / `鲸鲸` / `鲸鱼娘` / `鲸鱼` / `肥鱼` / `小肥鱼` 之一 —— 这条必接，不吃频率闸、不掷骰子。
- **主人说话**：`主人` 名单里的 wxid 发来的消息**必接**，前缀会标「这条是主人本人说的」；群上下文里也会标
  `~卡农.Z（主人）`，鱼鱼自己发过的标 `鱼鱼（我自己发的）`，其他人是昵称。
- **私聊**：所有好友的私聊都会接。
- 群里所有消息（不管回没回）按天进日记。
- 不回名单：微信运动、微信团队、微信支付、服务通知、订阅号消息、折叠的群聊。

### 表情包（2026-11-06 加的）

## 6.5 「问题修复：」—— 微信里直接派活

主人在微信里（任何聊天窗口）发一句带 **`问题修复：`** 的话：

```
问题修复：群里别人说话它老是不接，改成该接就接
```

桥接不会把它当聊天，而是：

1. 立刻回你一句「收到～鱼鱼记下了，这就去弄。」；
2. 把冒号后面的内容转进**开发会话**（配置项 `修复会话`，现在是这间干活会话 `session-ae57…`），
   我在这边收到后直接改代码；
3. 改完我用 `POST /dsh-wechat-bridge/send` 把结果发回那个微信聊天。

- **只认主人**（`主人` 里的 wxid）。别人发「问题修复：…」会被直接拒掉，日志记一行「不是主人发的」。
- 冒号中英文都行，`问题修复` 前面后面有没有空格都认；冒号后面的内容就是正文。
- 想换目标会话：改配置里的 `修复会话`。

## 7.5 长期记忆（2026-11-05 加的）

档案在 `%USERPROFILE%\.dsh\wechat-memory.json`：

```json
{
  "chats":  { "<群id 或 wxid>": { "name": "群名", "kind": "群/私聊", "summary": "这个群在聊什么、有哪些在办的事", "n": 42, "last_daily": "2026-11-11" } },
  "people": { "<wxid>":         { "name": "昵称", "impression": "对这个人一句印象（身份、风格、在意什么、是不是主人）",
                                  "days": { "2026-11-11": "他今天说了什么、有什么新信息" } } }
}
```

- **滚动更新**：每个聊天攒够 **12 条**新消息，后台线程调一次 DeepSeek，把「旧档案 + 新记录」压成新档案（只输出 JSON）。
- **每日总结**（2026-11-12 加的）：每天 **00:10 之后**自动跑一次，总结**昨天**所有聊天——
  每个聊天一段摘要，每个人一行「今天他说了什么」存进 `people.<wxid>.days`，只留最近 **7 天**。
  桥接重启时如果昨天还没总结过，会立刻补跑。日志里能看到 `每日总结完成：N 个聊天｜2026-11-11`。
- **怎么用**：回话前塞进消息开头——
  `（你记得这个群：…）（你对「~卡农.Z」的印象：…；聊过 16 次，好感度 3.2）（上次跟他聊到：…）`
  最后那句来自 `days` 里最近一个「今天之前」的记录，所以当天聊的不会重复出现。
- **好感度**：宿主照旧记在 `wechat-affinity.json`（聊过几次、分数），档案注入时带上。
- **想清空**：删掉 `wechat-memory.json` 重启桥接即可重建。
- **阈值**：环境变量 `DSH_WECHAT_MEM_THRESHOLD`（默认 12）。
- 首次启用用 `wechat-bridge-setup\backfill_memory.py` 灌过历史（两个群 + 你的私聊）。

## 7.6 「草稿泄漏」那件事

模型偶尔会把自己的修改过程写进正文——09:10 群里漏过一串
`… — no, avoid the emoji bracket? … Final: three lines, drop the last emoji. …`，看着像精神分裂。

两道闸：

1. **人设里禁止**：明写「输出就是发出去的那句话本身，不要 Final:/草稿:/重来一遍，不要自我点评」。
2. **发送前截断**：`去过程话()` 遇到 `Final:`、`— no,`、`no, avoid`、`It's fine as text`、`草稿：`、`重来一遍`
   这些标记就切在那里，只留前面那版正经答案；切没了就原样发。

## 8. 我对上游做了什么（都在本机副本里）

上游是 [thawline/dsh-wechat-bridge](https://github.com/thawline/dsh-wechat-bridge) v1.3.4。

1. **发消息前先记账**（`bridge/wechat_bridge.py`）
   原来「刚发出去的话」是在 `send_msg()` 返回**之后**才记账；UIA 打进微信和记账之间的空档，
   监听线程会把自己发的话当成「主人新说的」读回来 —— 实测中过一次，凭空开了一轮。现在发之前就记上。

2. **人设前缀**（`bridge/wechat_bridge.py` 的 `PERSONA`，每间聊天每天一次）
   顺带在 `lib/host.js` 加了 `人设` 配置项（宿主人设，留空不加）。

3. **`ctx.agents.resume()` 必须带 `agentOptions`**（`lib/host.js`）
   这是最坑的一个：不带模型路由恢复出来的会话，`followup` 之后**一轮立刻结束、事件一个都不落**，
   日志里只看得到 `turn/end`。踩了三次才定位到。现在恢复时带 `{ provider: 'deepseek-account', model: 'deepseek-flash' }`，
   所以 DSH 重启后会话能自己接上。

4. **`POST /dsh-wechat-bridge/session/new`**（`lib/host.js`）
   给桥接建一间「本进程自己养」的会话：`ctx.agents.create({ sessionId, agentOptions })`。
   建完自动写进配置（`默认会话` + `自养会话`）。`GET /dsh-wechat-bridge/session/created` 看建过哪几间。

5. **认主人**（`bridge/wechat_bridge.py`）
   文件传输助手里的消息一律算主人说的（手机发的消息常常不带 `sender_username`，原来会被当成外人）；
   群里主人自己说话时，只有**点了名**才转进来当「在叫它」，不点名的闲聊不接。

6. **活跃群进宿主配置**（`lib/host.js`）
   `活跃群` 原来只有 Python 侧会读，宿主一保存配置就把它丢了（归一化不认这个字段）。现在进了默认配置 + 归一化。

7. **拆条上限 26 → 60**（`bridge/wechat_bridge.py` 的 `拆条`）
   26 字一条，一段正经回答会被切成五六个气泡，群里像刷屏。

8. **引用消息里的原始 XML**（`bridge/wechat_bridge.py` 的 `_引用人话`，2026-11-06）
   群里有人**引用一张图片**再说话时，微信把被引用那条的原文塞在 `<refermsg><content>` 里 ——
   而图片消息的原文就是 `<img ...>` 的 XML。原样喂给模型，它就会对着源码讲「这一串是微信图片消息的原始 XML」。
   现在按类型换成一句人话（一张图片 / 一段视频 / 一条语音 / 一个表情包），其它 XML 剥标签留文字。

9. **纯表情回复的回环**（`bridge/wechat_bridge.py`）
   只发一个表情时没有文字，「刚发过」的时间戳没更新，自己发的表情会被文件传输助手读回来再触发一轮。
   现在发图前后都记账，防回环窗口 12s → 30s。

改了 `lib/host.js` 之后让它生效：改文件 → **在 `~/.dsh/profiles/desktop/cordis.patch.yml` 里加一行注释**（触发 profile 热重载）→
插件会在 20 秒内重新挂载（桥接进程会被带走，要重新「启动」）。只改 Python 的话重启桥接就行。

## 9. 已知边界 / 风险

- **用的是你自己的微信号**。朋友收到的就是「你」在说话。个人号自动化不是官方接口，**有封号风险**，建议先小范围跑。
- **发消息可能抢焦点**：正常不抢前台；只有发送失败重试时才会把微信拉到前面，切私聊↔群时窗口会短暂露一下。
- **同一个号别同时开两个桥**（会抢窗口、发送乱）。
- 微信升级可能让它失效：`wechatauto` 靠按版本号硬编码的控件树找输入框。发不出去先看桥接日志。
- 只支持 Windows（UI Automation）。
- 图片/表情包会先用视觉模型看一遍再转进会话。**微信 4.x 的新图片格式 `.wxgf` 要 ffmpeg 转码**，
  ffmpeg 装在 `~/.dsh/wechat-bridge-runtime/bin/ffmpeg.exe`（宿主 spawn 桥接时会把这个目录顶到 PATH 前面）；
  启动日志里有 `ffmpeg： <路径>` 一行，显示「没找到」就说明转码没戏，那种图只能回「没看清」。
- 视频 / 语音：**2026-11-06 起**会转成「（发来一段视频/语音）」给模型（以前直接跳过，等于没看见）；
  分享卡片没标题时会把链接本身带上。
- 微信必须**保持登录**（读库密钥要从运行中的微信进程里取）。
- 桥接每次启动会给**你自己**发一句「我回来啦。今天也在。」+ 一张表情包，一天最多一次。
  不想要就注释掉 `wechat_bridge.py` 里 `_连上撒娇()` 的线程启动那行。

## 10. 出问题看哪里

1. `%USERPROFILE%\.dsh\wechat-bridge-host.log` —— 收到什么、转进哪间、该发什么、发送成没成。
2. `...\dsh-wechat-bridge\bridge\bridge.log` —— 连库、收消息、发送失败重试。
3. `GET /dsh-wechat-bridge/state` —— 两边日志 + 最近聊天 + 待发队列 + 活着的会话。
